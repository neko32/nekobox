# コマンド

/emotion [emotion名] ... 指定したエモーションリアクションをモデルに起こさせる。DBにもバックエンドにも送られることはない。

/new [セッションエイリアス] ... 新しいセッションを作って

/tts on ... TTS（音声読み上げ）を有効にする。設定は app.config に保存される。

/tts off ... TTS（音声読み上げ）を無効にする。設定は app.config に保存される。

/tts voices ... システムで利用可能な TTS 音声の一覧と現在使用中の音声 ID をチャットウィンドウに表示する。

/tts [テキスト] ... 指定したテキストをテスト発話させる。引数なしの場合はデフォルトのテストメッセージを読み上げる。
